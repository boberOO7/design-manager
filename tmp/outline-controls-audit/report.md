# Аудит кнопок з рамкою

Обсяг: нейтральні кнопки з рамкою в застосунку, кнопки хедера та еквівалентні кнопки-посилання. За основу взято погоджений hover календарних кнопок: фон `--ui-surface-strong`, рамка `--ui-text-muted`, текст `--ui-text`, перехід 180 мс.

## Спільна реалізація

`src/app/globals.css` — клас `ui-outline-control` визначає hover та відкритий стан, підтримує світлу/темну тему, reduced motion і вимкнення анімацій. Hover працює для точного вказівника. Disabled, aria-disabled, вибрані та hold-to-confirm стани захищені від нейтрального hover.

- `src/components/ui/button.tsx`: усі `Button variant="outline"` автоматично використовують цей клас.
- `src/components/layout/shell-control.tsx`: такий самий клас для теми, сповіщень, виходу та перемикача мови.
- `src/components/ui/select.tsx`: `variant="secondary"` уже використовує `buttonVariants({ variant: "outline" })`, тому отримує той самий стиль.

Календарні дублікати hover/open-стилів, окремі `.header-icon-control` правила та дубль у Finance Expected видалено. Розміри, маршрути, запити та обробники дій збережено.

## Замінені ручні реалізації

- Кнопка мобільного меню → `ShellControl`.
- Вибір власного періоду Leaderboard → `Button outline`.
- Завантаження наступних сповіщень і відхилення запрошення → `Button outline`.
- Повернення до входу на сторінці помилки авторизації → `Button asChild outline`.

## Особливі стани

- `ui-outline-danger` задає семантичні кольори через CSS-змінні та використовує ту саму реалізацію станів. Застосовано до кнопок видалення вихідних компанії.
- Власний колір hover кнопки збереження контактів у редакторі пропозиції збережено через CSS-змінну.
- Власний pressed-стан вторинних кнопок Finance Expected збережено через CSS-змінну.
- Індикатор утримування для скасування події зберігає власні кольори.
- Glow основної кнопки календаря та поведінка вибраної календарної вкладки збережені.
- Поля форм, картки, колірні зразки, навігаційні вкладки й borderless/ghost-кнопки мають інший тип взаємодії та не переведені на outline-стиль.
