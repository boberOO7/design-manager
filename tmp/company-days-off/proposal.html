Додати тиждень вихідних за одне збереження

Залишаємо знайому бічну панель. Період залишається одним записом у списку: з власною назвою, початком і кінцем. Його можна редагувати або видаляти цілком.

  1. Натисніть «Додати вихідні».
  2. Для тижня виберіть першу та останню дату в календарі. Один день — двічі ту саму дату.
  3. Для дат із перервами перемкніть «Окремі дати».
  4. Натисніть на збережений період, щоб змінити його. Для видалення оберіть його прапорцем у списку.

Інтерактивний макет. Усі зміни живуть лише в пам’яті цієї сторінки. Бази даних і API застосунку він не торкається.

У списку вже є «Зимові канікули · 7–10 січня 2027». Це один період. При його редагуванні власні дати не спричиняють конфлікту; перетин з іншим записом буде позначено.
