Fonts used by the Commercial Proposal design variants and development comparison workspace.

- IBM Plex Serif Regular: unmodified font from the installed canvas-design assets.
- Jura Medium: unmodified font from the installed canvas-design assets.
- SPACE Design Mono: IBM Plex Mono Regular reserialized with fontTools to repair glyph bounds that the installed PDF font engine could not decode. The derivative family was renamed to respect the reserved font name in the SIL Open Font License. The original copyright and license are retained in IBM-Plex-LICENSE.txt.

Ubuntu remains the existing application font asset. The original `classic` proposal still uses its existing font registration.
